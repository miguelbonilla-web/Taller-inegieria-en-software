¿Qué aprendí?

En este taller aprendí a moverme por el computador usando la terminal de PowerShell, organizar archivos y carpetas sin usar el mouse, y a usar Git para guardar y compartir el historial de mi proyecto en GitHub.

Comandos que usé

  • mkdir — crear carpetas
  • ni — crear archivos vacíos
  • move — mover archivos
  • git init — iniciar un repositorio
  • git add — preparar cambios
  • git commit — guardar una fotografía del proyecto
  • git push — subir cambios a GitHub
